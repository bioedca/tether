# Tether documentation

Tether is a cross-platform desktop suite for quantitative single-molecule FRET (smFRET) analysis. It carries experiments from movies through trace curation, idealization, and reproducible analysis without losing provenance.

Use the documentation site's [version selector](https://bioedca.github.io/tether/latest/) to match these guides to your installed Tether release.
