# Tether

Tether is a cross-platform desktop suite for quantitative single-molecule FRET (smFRET) analysis.
It carries an experiment from raw movies through trace curation and idealization to reproducible,
provenance-stamped analysis.

## [Read the documentation →](https://bioedca.github.io/tether/)

The site is versioned. Use the **version selector** in the header of any documentation page — it is
built from [`versions.json`](https://bioedca.github.io/tether/versions.json) — to match the
documentation to the Tether release you have installed.
