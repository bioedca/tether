    Architecture Decision Records (ADRs)

    This directory records Tether's architecture decisions in MADR format. Each ADR captures one decision, its context, the options weighed, and the consequences, so the rationale survives prose harmonization of the PRD (PRD §12.7).

    How ADRs are created

    • New file: NNNN-kebab-title.md, copied from 0000-template.md, NNNN = the next zero-padded integer.
    • Incremental rule (PLAN §0.4 DoD). A PR that implements a still-unhomed resolved PRD decision lands that decision's ADR in the same PR.
    • M9 gate. The M9 docs PR fails unless this index is complete (no placeholder gaps) — closing PRD §12.7's "home the resolved decisions" deliverable.
