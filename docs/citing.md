# Citing Tether

Use the repository's
[`CITATION.cff`](https://github.com/bioedca/tether/blob/main/CITATION.cff), exposed by
GitHub's **Cite this repository** menu, as the machine-readable source for Tether's
authors, title, license, and release metadata. Cite the exact released version used for
an analysis; release tags add that version's date and DOI to the file.

Tether interoperates with tMAVEN and mirrors published methods from Deep-LASI,
MASH-FRET, and SMD. Cite those upstream works when their methods or formats contribute
to the reported analysis; their identifiers and roles are recorded in
[`CITATION.cff`](https://github.com/bioedca/tether/blob/main/CITATION.cff) and
[`NOTICE`](https://github.com/bioedca/tether/blob/main/NOTICE).
